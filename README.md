# 🌍 Lingua Franca

**Lingua Franca** is a web-based translation interface built with Flask and the Google Translate API. It allows users to write a text in any language, automatically detect the input language (or select it), and get a translated version in another language — all in a sleek, futuristic UI.

---

## 🚀 Project Context

This project was developed as part of a learning exercise at [La Plateforme](https://laplateforme.io), focusing on the use of public APIs, web development with Python (Flask), and the creation of interactive, user-friendly web interfaces.

The challenge was to:

- Create a Flask application allowing users to translate text.
- Connect to Google’s translation API.
- Design a visually appealing and responsive interface using custom CSS and JavaScript.

---

## 🛠 Features

- 🔤 Text translation from any source language to any target language.
- 🧠 Automatic language detection.
- 🎨 Futuristic neon-glow responsive UI.
- 💡 JavaScript-enhanced user experience with subtle animations and effects.

---

## 📦 Technologies Used

- Python 3
- Flask
- Jinja2
- Google Translate API (via `googletrans` or `requests`)
- HTML/CSS (custom styling)
- JavaScript (animations & interactivity)

---

## 🔧 How to Run It

1. **Clone the repository:**

```bash
git clone https://github.com/YOUR_USERNAME/lingua-franca.git
cd lingua-franca
```

2. **Install dependencies:**

```bash
pip install -r requirements.txt
```

3. **Run the app:**

```bash
python run.py
```

4. **Open in your browser:**

```
http://127.0.0.1:5000
```
